# AI Email Triage Assistant

## 📌 Description
AI Email Triage Assistant is an intelligent email management system that automatically classifies incoming emails, generates draft responses, and routes messages to appropriate platforms such as Slack or Notion.

---

## 🚀 Features
- AI-powered email classification
- Automated draft reply generation
- Spam and priority detection
- Slack and Notion integration
- Inbox automation workflow

---

## 🛠️ Tech Stack
- TypeScript
- Node.js
- Vite
- Gemini API
